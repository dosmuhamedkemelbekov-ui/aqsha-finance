# AQSHA

Устанавливаемое PWA для личных финансов: доходы, расходы, категории, регулярные платежи и цели.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовая сборка появится в `dist`. Проект настроен с относительными путями и подходит для публикации на GitHub Pages.

## Возможности MVP

- общий баланс, доходы и расходы;
- быстрое добавление операций;
- категории расходов и месячный лимит;
- список регулярных платежей;
- отметка оплаченных платежей;
- локальное сохранение данных в браузере;
- поиск и фильтрация операций;
- финансовые цели и пополнение накоплений;
- экспорт и импорт резервной копии;
- редактируемый профиль и месячный бюджет;
- адаптивный мобильный интерфейс;
- установка на телефон и офлайн-работа через service worker.
- отдельные счета, кошельки и переводы между ними;
- переключение месяцев и сравнение доходов с расходами;
- бюджеты по категориям и план-факт;
- календарь, автоматические платежи, долги и рассрочки;
- аналитика за шесть месяцев;
- локальные напоминания и PIN-защита;
- опциональная облачная синхронизация через Supabase.

## Облачная синхронизация

1. Создайте бесплатный проект в Supabase.
2. Выполните файл `supabase.sql` в SQL Editor проекта.
3. В GitHub откройте **Settings → Secrets and variables → Actions**.
4. Добавьте секреты `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. Повторно запустите workflow публикации.

Для локальной разработки скопируйте `.env.example` в `.env.local` и укажите значения проекта. Без Supabase все функции, кроме синхронизации между устройствами, продолжают работать локально.

## Установка на телефон

Приложение должно быть опубликовано по HTTPS (например, через GitHub Pages).

- Android / Chrome: откройте сайт и нажмите «Установить приложение» или пункт «Добавить на главный экран» в меню браузера.
- iPhone / Safari: нажмите «Поделиться», затем «На экран Домой».

После первого открытия приложение и его интерфейс доступны без интернета. Финансовые данные хранятся локально на устройстве, поэтому периодически создавайте резервную копию в разделе «Настройки».

## Публикация на GitHub Pages

В проект уже добавлен GitHub Actions workflow. Загрузите код в ветку `main`, затем в настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника. После каждого push сайт будет собираться и публиковаться автоматически.
